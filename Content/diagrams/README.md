# Схемы

`questions/` содержит четыре общих PNG без печатного ответа:

- таблица префиксов CEPT — вопросы 22 и 23;
- таблица национальных лицензий HAREC — вопрос 32;
- схема FM‑передатчика — вопросы 173–176;
- схема супергетеродинного приёмника — вопросы 177–180.

Связи 11 вопросов с четырьмя файлами, страницы, crop‑координаты и факт визуальной проверки записаны в `questions/figure-manifest.json`. Фрагменты воспроизводятся командой:

```bash
python3 Tools/extract_figures.py
```

CI устанавливает Poppler, повторяет это извлечение из неизменённого `Справочник_КЭ.pdf` и требует `git diff --exit-code` для PNG и manifest. Таким образом, зафиксированные изображения проверяются не только по размеру и mapping, но и побайтно воспроизводятся из crop-спецификаций.

`teaching/` содержит дополнительные учебные SVG/PNG для карточек терминов. Они не заменяют экзаменационные рисунки и показываются только в объяснениях.
