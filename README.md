# HAM Trainer 3

Нативный офлайн‑тренажёр для подготовки к экзамену радиолюбителя третьей категории в России.

![macOS 14+](https://img.shields.io/badge/macOS-14%2B-111111?logo=apple)
![Swift 6](https://img.shields.io/badge/Swift-6-F05138?logo=swift&logoColor=white)
![218 вопросов](https://img.shields.io/badge/банк-218_вопросов-2f7d6d)
![Offline](https://img.shields.io/badge/режим-offline-335c81)

HAM Trainer 3 написан на SwiftUI и работает без аккаунта, сети, телеметрии и API‑ключей. Банк содержит ровно 218 вопросов третьей категории, подробные русские объяснения, тематический справочник, умное повторение и пробный экзамен.

![HAM Trainer 3 — обзор](docs/screenshots/final-qa/01-dashboard-1366-light-large.png)

## Возможности

- точные диапазоны третьей категории: `1–34`, `47–98`, `100–135`, `150–226`, `387–391`, `409–422`;
- умная очередь с расстояниями `5 → 10 → 20 → 40 → 80` завершённых карточек и защитой от слишком раннего повтора;
- короткое, начальное и пошаговое объяснение каждого вопроса, а также разбор трёх неверных вариантов;
- справочный просмотр по темам: официальный ответ виден сразу, а обучение запускается одной кнопкой;
- 25 уникальных вопросов на пробном экзамене, проходной результат 20/25, отдельный учёт неверных и неотвеченных;
- 127 встроенных терминов, реально используемых этим банком, личный словарь, заметки, поиск, фильтры и закладки;
- четыре проверенных общих экзаменационных изображения для вопросов 22, 23, 32 и 173–180; печатные красные ответы в изображения не включены;
- локальная статистика и резервная копия JSON с собственной идентичностью HAM Trainer 3.

## Быстрый старт

Требуются macOS 14+ и Xcode Command Line Tools либо Xcode со Swift 6.

```bash
git clone https://github.com/Leo0742/HAM-Trainer-3.git
cd HAM-Trainer-3

Tools/run_tests.sh
Tools/build_app.sh
open "Build/HAM Trainer 3.app"
```

Скрипт создаёт release‑пакет `.app`, иконку и локальную ad‑hoc подпись. Проект `HAMTrainer3.xcodeproj` можно открыть в Xcode; target/scheme и исполняемый файл имеют имя HAMTrainer3.

## Обучение и данные

После каждого завершённого ответа увеличивается общий `studyStep`. Повтор назначается не на дату, а после нужного числа других завершённых карточек. Неправильный ответ, «Не знаю» и просмотр ответа до попытки считаются ошибками. В обычной сессии карточка возвращается только после пяти других вопросов и не чаще двух раз.

Данные HAM Trainer 3 не пересекаются с прежним приложением и сохраняются в:

```text
~/Library/Application Support/HAMTrainer3/progress-v1.json
```

Экспорт имеет идентичность `HAMTrainer3`. Резервная копия другой категории отклоняется до изменения текущего прогресса.

## Контент и воспроизводимость

Конвейер разделяет источник и производный учебный слой:

1. `ContentRaw/` хранит нормализованное извлечение из двух PDF;
2. `ContentAuthored/third-category-218-explanations.json` — неизменяемый, защищённый SHA‑256 учебный слой для точных 218 вопросов;
3. `ContentOverrides/question-overrides.json` содержит только явно проверенные исправления извлечения и сопоставления ответа;
4. `Tools/build_content.py` собирает runtime-банк и оставляет в нём только используемые термины;
5. валидатор и аудиты проверяют диапазоны, формулировки, варианты, ответы, объяснения, глоссарий, изображения и хеши PDF.

```bash
python3 Tools/build_content.py
python3 Tools/validate_content.py
python3 Tools/audit_answer_matches.py
python3 Tools/audit_content.py
```

Текущий результат: 218/218 авторских записей, 0 fallback, 127 терминов, 215 exact + 3 explicit manual сопоставления, 0 fuzzy. Подробности: [`docs/content-audit.md`](docs/content-audit.md), [`docs/answer-match-audit.md`](docs/answer-match-audit.md) и [`docs/source-provenance.md`](docs/source-provenance.md).

## Проверка

`Tools/run_tests.sh` запускает 54 нативные проверки: планировщик и 500‑ответную симуляцию, точный банк, пробный экзамен 25/20, тематический справочник, резервные копии, глоссарий и обязательные изображения. Workflow `.github/workflows/ci.yml` повторно собирает контент, запускает аудиты и тесты, проверяет отсутствие diff и создаёт release app.

Контрольные снимки интерфейса и чек‑лист находятся в [`docs/final-visual-qa.md`](docs/final-visual-qa.md).

## Исходные материалы и права

Полученные PDF сохранены без изменений в `ExamSources/`; их контрольные суммы и назначение приведены в [`ExamSources/README.md`](ExamSources/README.md). Репозиторий не присваивает этим документам лицензию исходного кода. Приложение не выполняет сетевых запросов, весь пользовательский прогресс остаётся на Mac.
